# learn-english-w-ai

Это интерактивное приложение для пополнения словарного запаса английского языка, созданное на базе искусственного интеллекта и уникальной методики запоминания. Выберите любую интересующую вас тему, запустите тест и переводите подобранные слова. Отвечайте на вопросы, оценивайте свой прогресс и изучайте детальный разбор ошибок в конце. Работает с любым языком - необходимо просто написать тему на языке, которая нужна.

Установка:
1. Скачайте или клонируйте репозиторий
2. Создайте файл: `"keys.json"` с контентом:
```json
{

}```
3. Запускайте проект через консоль командой: `flutter run --dart-define-from-file=keys.json`
